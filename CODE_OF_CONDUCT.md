# Code of Conduct

## Purpose

This project exists to help people build practical Discord bots responsibly.
All community activity should support fair use, user safety, and legal compliance.

## Our Standards

Examples of behavior that contributes to a positive environment include:

- being respectful, constructive, and professional
- focusing feedback on code, documentation, and design decisions
- being transparent about limitations, risks, and tradeoffs
- prioritizing privacy, consent, and safety in technical decisions
- documenting potentially risky behavior and adding safeguards by default

Examples of unacceptable behavior include:

- harassment, intimidation, or personal attacks
- discriminatory, hateful, or sexually abusive language or content
- deliberate misinformation, evasion, or bad-faith security behavior
- sharing secrets, tokens, user data, or sensitive configuration from others
- proposing or submitting code that enables harmful or exploitative use

## Responsible-Use Expectations

Contributors and users must not use this repository to create, promote, or automate:

- unlawful activity
- scams, fraud, phishing, or deceptive impersonation
- harassment, doxxing, stalking, or targeted abuse
- malware distribution, unauthorized access, or surveillance abuse
- exploitative gambling workflows, especially those targeting minors, at-risk users, or financially vulnerable groups
- systems designed to manipulate sensitive audiences (including children) toward harmful behavior

When uncertainty exists, choose the safer path and ask maintainers for review before merging or publishing.

## Scope

This Code of Conduct applies to repository discussions, issues, pull requests, project boards, and other project-managed spaces.

## Enforcement

Project maintainers may remove, edit, lock, reject, or revert content that violates this Code of Conduct.
Maintainers may also restrict participation (temporary or permanent) for repeated or severe violations.

## Reporting

Report violations privately to the repository maintainer.
Please include:

- where the issue occurred
- relevant links or screenshots
- a concise description of what happened
- immediate safety concerns, if any

All reports are reviewed in good faith. Retaliation against reporters is prohibited.
